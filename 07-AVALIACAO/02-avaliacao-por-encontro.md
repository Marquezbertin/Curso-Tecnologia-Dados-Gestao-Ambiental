# Avaliação por Encontro

Checklist rápido para o professor registrar a entrega e o nível de cada grupo. Use a
[rubrica geral](01-rubrica-avaliacao.md) para converter em nível 1–4.

---

## Como usar

1. Ao fim de cada encontro, circule o nível de cada grupo (1 a 4).
2. Anote uma evidência concreta (o que o grupo fez ou não fez).
3. Registre o próximo passo para o encontro seguinte.
4. Não use a avaliação para reprovar: use para ajustar a próxima aula.
