# Plano B — Offline, sem internet e sem computador

O curso foi desenhado para **não parar** quando a tecnologia falha. Toda atividade tem uma versão
que roda no papel, no celular ou com dados impressos. A regra é: **a aula acontece de qualquer
jeito**.

---

## 1. Princípios

1. Nenhuma aula depende de internet estável.
2. Nenhum aluno fica de fora por não ter aparelho.
3. O dado impresso é tratado como dado: tem fonte, período e limitação.
4. A versão offline não é "aula menor": é a mesma competência por outro caminho.

## 4. Atividade de emergência: "o computador sou eu"

Quando não há nenhum computador, use esta dinâmica de 20 min (funciona em qualquer encontro):

1. O professor escreve um trecho de código no quadro.
2. A turma vira o "computador": cada aluno é uma variável.
3. O professor "executa" linha por linha e pergunta: "qual é o valor agora?"
4. Um aluno registra a saída no quadro.
5. Depois, a turma compara com o resultado esperado.

**Conceitos que funcionam bem:** variável, lista, média, filtro, condição, laço.

---

## 5. Atividade de emergência: "dado na mão"

1. Distribua a tabela impressa.
2. Peça que cada grupo calcule a média de uma coluna.
3. Confira no quadro, com a turma.
4. Peça um gráfico de barras no papel.
5. Feche com a pergunta: "o que esse dado não mostra?"

## 7. Se o Colab não abrir

1. Verifique a conexão e tente outra conta Google.
2. Use o Python local, se houver computador com Python instalado.
3. Use a planilha como ambiente de análise.
4. Use a versão impressa da atividade.
